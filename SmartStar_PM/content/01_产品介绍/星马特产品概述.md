# 产品定义

星码特全域店商数智赋能平台是一款面向中小微企业的数字化孵化与全域营销工具服务商，采用 S2B2C（Supply to Business to Consumer）商业模式。该模式通过平台连接供应商（S）、商家/合伙人（B）和消费者（C），实现多方共赢生态。

平台以"消费积分 + 多级推广 + 商家补贴 + B端批发进货"为核心，打通线上商城 + 线下门店 + 云店选品 + B端批发采购，提供免费入驻、秒级结算、锁客裂变、积分通兑、B端批发分润等服务，构建供应商、用户、推广者、商家、合伙人多方分润体系，目标打造千城万盟万亿级消费积分生态平台，最终实现数据资产化与资本驱动上市。


# 商业模式

星马特全域店商数智赋能平台是采用 S2B2C 模式，通过面向本地生活与线上消费的、集供应链、商家入驻、会员分销、门店 O2O、资金结算于一体的新零售综合服务平台。

平台核心模式包含：
- S2B2C 电商模式
- B2C 商家入驻商城
- B2B 批发进货（门店向供应商批量采购）
- O2O 本地生活门店
- 云店模式”社交电商+新零售”轻资产模式
- 会员 / 合伙人 / 团队分销裂变
- 完整支付结算分佣体系（B2C消费分润 + B2B批发分润）
- 全套运营营销工具


# 目标用户与场景

## 目标用户

- **普通消费者**：期待消费能产生长期价值，积分、红包与会员权益贯穿线上线下购物。
- **供应商**：希望拓展销售渠道、降低获客成本、通过平台开设线上官方店铺触达消费者，同时向门店供货实现B2B/B2C双渠道销售。
- **线下门店老板**：希望借助线上流量引流到店，提升本地客流与复购；同时支持B2B批发进货，降低采购成本。
- **推广专员 / 推广经理 / 区域代理合伙人**：希望通过裂变获客、管理团队、获得清晰佣金与升级激励。
- **个体户 / 云店合伙人**：希望低成本开店、共享供应链与流量、实现社交转化与收益共赢。

## 角色洞察

- **普通消费者**
  - 核心痛点：消费场景碎片化，缺少长期回报，线上线下权益无法统一。
  - 关键场景：在本地商圈、云店和线上商城购物；参与签到、拼团与红包活动；通过邀请关系获取推荐奖励。
  - 期望价值：消费即获积分与红包、会员等级升级带来权益增值、购物过程简单直观、权益闭环统一。

- **供应商**
  - 核心痛点：传统分销渠道层级多、库存积压风险高、收款周期长；线上店铺运营能力弱、流量获取难。
  - 关键场景：入驻平台 → 开设线上官方店铺（B2C销售）→ 向门店供货（B2B批发）→ 发货结算。
  - 期望价值：减少中间环节、快速触达门店与消费者、B2B+B2C双渠道出货、D+1结算货款、平台流量赋能线上销售。

- **线下门店老板**
  - 核心痛点：本地客流不足、线上推广能力弱、线下消费缺乏闭环留存手段；采购渠道分散、价格不透明。
  - 关键场景：将门店商品与服务接入商圈、提供扫码支付与核销、发起门店活动与补贴策略；通过B2B批发从供应商采购。
  - 期望价值：线上引流到店、消费积分激励复购、门店活动带动客流、形成 O2O 数据闭环；B2B采购降低成本、丰富商品品类。

- **推广专员 / 推广经理 / 区域代理合伙人**
  - 核心痛点：获客渠道单一、裂变管理复杂、佣金计算不透明、团队激励难落地。
  - 关键场景：生成邀请海报与推广素材、分享给好友、管理团队业绩、监控佣金与晋升进度。
  - 期望价值：稳定佣金与积分收益、清晰晋升路径、裂变流程可视化、推广成果可沉淀为资产。

- **个体户 / 云店合伙人**
  - 核心痛点：缺少品牌与供应链支持、自建电商成本高、单店引流效果差。
  - 关键场景：从消费者升级为专员后开通云店、选择供应链商品入驻、通过社交与推广渠道售卖。
  - 期望价值：低成本开店、共享供应链与平台流量、商品快速上架、用户与自己双向分润。
  - 关键场景：从消费者升级为专员后开通云店、选择供应链商品入驻、通过社交与推广渠道售卖。
  - 期望价值：低成本开店、共享供应链与平台流量、商品快速上架、用户与自己双向分润。

## 核心业务场景

### 用户侧场景
| 场景 | 流程 |
|------|------|
| 会员注册与成长 | 用户注册 → 完善资料 → 购买推广商品 → 成为推广专员 → 晋升推广经理 → 晋升合伙人 |
| 商城购物 | 浏览商品 → 加入购物车 → 结算 → 支付 → 商家发货 → 收货 → 评价 |
| 积分兑换 | 消费获积分 → 进入积分商城 → 使用积分兑换/抵扣 → 获得商品 |
| 拼团活动 | 发起/参与拼团 → 支付拼团价 → 邀请好友参团 → 拼团成功等待发货 |
| 推广裂变 | 生成邀请码/海报 → 分享好友 → 好友注册绑定关系 → 好友消费 → 推广者获得佣金 |
| 签到抽奖 | 每日签到获积分 → 签到抽奖 → 消耗积分参与抽奖 → 中奖获得奖励 |
| 线下门店消费 | 浏览附近门店 → 到店消费 → 扫码支付 → 门店核销 → 获得积分/红包 |

### 商家侧场景
| 场景 | 流程 |
|------|------|
| 线上商家入驻 | 提交入驻申请 → 平台审核 → 签署协议 → 创建店铺 → 上架商品 → 开始营业 |
| 线下门店入驻 | 提交门店资料 → 平台审核 → 入驻商圈 → 上架商品/服务 → 开启核销 |
| B2B批发进货 | 门店发起采购 → 选择供应商商品 → 确认采购数量 → 提交订单 → 供应商确认 → 付款结算 → 供货商发货 → 门店收货 |
| 商品管理 | 添加商品 → 设置规格属性 → 设置价格与库存 → 提交审核 → 上架销售 |
| 订单处理 | 接收订单 → 确认订单 → 打单发货 → 等待买家收货 → 订单完成 |
| 售后处理 | 买家申请退款/退货/换修 → 商家审核 → 处理退款/退货/换货 |
| 结算提现 | 查看结算记录 → 申请提现 → 平台打款 → 到账 |

### 供应链场景
| 场景 | 流程 |
|------|------|
| 供应商入驻 | 提交入驻申请 → 平台审核 → 签署协议 → 创建店铺 → 上架商品 → 开始营业 |
| 云店开通 | 购买推广专员商品 → 成为专员 → 申请开通云店 → 供应链选品 → 开始经营 |
| 供应链采购（云店） | 供应链选品 → 查看毛利率与指导价 → 选择商品加入云店 → 用户下单 → 转售 |
| B2B供货 | 接收门店采购订单 → 确认价格与数量 → 发货 → 等待结算 |
| B2B货款结算 | 门店付款 → 平台分账 → 供应商结算到账 |

### 平台运营场景
| 场景 | 流程 |
|------|------|
| 分润结算 | 用户消费 → 积分/红包计算 → 推广佣金计算 → 商家结算 → 供货商结算 → 佣金发放 |
| B2B分润结算 | 门店采购付款 → 平台分账 → 供应商结算 → 区域合伙人返利（如涉及） |
| 会员等级管理 | 会员消费与推广 → 业绩累积 → 达到晋升门槛 → 晋升更高级别 |
| 营销活动 | 平台创建活动 → 用户参与 → 奖励发放 → 活动数据统计 |

# 业务规则与分润体系

- 会员等级与权益：
  - 普通用户：任意消费1次，2%红包+10%积分，分享收益基础版
  - 推广专员：购买推广专员专区商品，5%红包+10%积分，享团队层级返利（下游1级）
  - 推广经理：购买推广经理专区商品，7%红包+10%积分，享团队层级返利（下游2级）
  - 区域合伙人：缴纳合伙人费用获得区域代理资格，7%红包+10%积分，享受区域内所有消费返利（按消费方归属区域判定）
  - **身份叠加**：推广专员/经理与区域合伙人身份可叠加，同时享受团队层级返利和区域消费返利
- 积分规则：消费积分、分享推广积分、积分兑换与抵扣。
- 红包规则：用户红包、商家红包、活动补贴。
- 结算规则：D+1 到账、商家分润、供货商结算、团队佣金。
- 订单规则：退款退货、换修货、售后流程、线下核销。
