## 一、需求背景

星码特平台用户端H5已有"我的粉丝"模块，供应商可在H5端查看通过推广链接/邀请码注册的用户（粉丝）数据。当前H5端功能较为简单，包含：
- 4项统计指标卡片：粉丝总数、累计粉丝、粉丝总业绩、个人总业绩
- 搜索功能：按粉丝ID/手机号搜索
- 粉丝列表：粉丝信息（头像/昵称/手机号）、累计消费、累计佣金、注册时间

供应商在PC端缺乏对应的分销团队管理和业绩统计分析工具，无法深入了解团队结构、业绩趋势和成员表现。需要在供应商PC端新增一个独立的"分销业绩统计"模块，提供更强大的数据管理和分析能力。

## 二、需求沟通详情

### 2.1 模块基本定位

| 确认项 | 确认结果 |
|--------|----------|
| 模块名称 | **分销业绩统计** |
| 所属终端 | 供应商PC端（`web_new/pc`） |
| 菜单位置 | 供应端下新增独立一级菜单，不与现有"合伙人管理"合并 |
| 核心目的 | 管理分销团队层级结构 + 监控分析销售业绩数据 |

### 2.2 数据来源与范围

| 确认项 | 确认结果 |
|--------|----------|
| 粉丝定义 | 通过供应商推广链接/邀请码注册的用户 |
| 团队层级 | 有多级层级关系（粉丝可发展下级粉丝），供应商可查看树形结构 |
| 数据穿透 | 供应商可查看多级粉丝的完整树形结构 |
| 个人中心 | 供应商个人总业绩也需要在模块中展示 |

### 2.3 PC端功能增强需求

相比H5端，PC端需要增加以下全部能力：

| 增强功能 | 说明 |
|----------|------|
| 时间维度筛选 | 今日/昨日/近7天/近30天/自定义时间范围 |
| 数据导出 | 支持导出Excel/CSV格式的团队业绩报表 |
| 团队层级展示 | 树形结构展示多级粉丝关系，支持展开/折叠 |
| 粉丝详情页 | 点击粉丝查看其详细业绩明细、下级粉丝数据 |
| 业绩趋势图表 | 折线图/柱状图展示团队业绩变化趋势 |
| 高级排序与筛选 | 按消费金额、佣金、注册时间等多条件排序和组合筛选 |

### 2.4 双维度设计

数据展示按**个人业绩**和**团队业绩**两个维度组织：

| 维度 | 说明 | 核心指标 |
|------|------|----------|
| 个人业绩 | 供应商自己作为推广者的销售业绩 | 个人累计消费、个人累计佣金、个人销售额趋势 |
| 团队业绩 | 下级所有粉丝的业绩汇总（含多级穿透） | 团队总业绩、各层级贡献占比、粉丝总数、新增粉丝数 |

**团队业绩层级拆解**：需要按层级拆解展示，明确区分一级粉丝贡献、二级粉丝贡献等各层级的业绩占比。

### 2.5 PC端页面布局

采用 **"统计卡片合并 + 列表Tab切换"** 布局方案：

```
┌─────────────────────────────────────────────────┐
│  分销业绩统计                                    │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐  │
│  │个人业绩 │ │团队业绩 │ │粉丝总数 │ │新增粉丝 │  │
│  │ ¥xxx   │ │ ¥xxx   │ │  xxx   │ │  xxx   │  │
│  └────────┘ └────────┘ └────────┘ └────────┘  │
│                                                  │
│  ┌─ 业绩趋势图（日/周/月切换）─────────────────┐ │
│  │  折线：个人业绩  柱状：团队业绩              │ │
│  └────────────────────────────────────────────┘ │
│                                                  │
│  [个人明细] [团队明细]    ← Tab切换              │
│  ┌─────────────────────────────────────────────┐ │
│  │ 列表数据（两Tab字段不同）                    │ │
│  └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

**布局说明**：
- 顶部4张统计卡片统一展示个人+团队核心指标，一眼全局
- 趋势图用折线（个人）+ 柱状（团队）双维度叠加，直观对比
- 列表区Tab切换："个人明细"展示消费/佣金记录，"团队明细"展示粉丝列表+层级

### 2.6 数据展示要求

| 确认项 | 确认结果 |
|--------|----------|
| 统计指标 | 个人业绩、团队业绩、粉丝总数、新增粉丝数 |
| 个人明细列表 | 订单/消费记录、佣金记录、收益明细等 |
| 团队明细列表 | 粉丝信息、累计消费、累计佣金、注册时间、团队人数、团队业绩、消费频次、客单价、最近消费时间、所属层级 |
| 图表类型 | 趋势折线图（个人业绩）+ 柱状图（团队业绩），支持日/周/月切换 |
| 图表时间粒度 | 按日、按周、按月三者都支持，可切换 |

### 2.7 与现有功能的关系

## 四、产品经理分析

### 4.1 初步判断

这是一个从H5移动端轻量查看 → PC端深度管理的典型需求升级。PC端"分销业绩统计"模块的核心价值在于：

1. **数据可视化**：将H5端的简单数字升级为趋势图、对比图，帮助供应商快速判断团队健康度
2. **团队透视**：树形结构让供应商清晰了解分销网络的广度和深度，识别关键推广节点
3. **精细化运营**：通过筛选、排序、导出等能力，供应商可以进行数据驱动的团队管理和激励决策

### 4.2 设计建议

**页面布局已确认**：采用"统计卡片合并 + 列表Tab切换"方案：
```
统计卡片（个人业绩/团队业绩/粉丝总数/新增粉丝）
    ↓
业绩趋势图（折线=个人 + 柱状=团队，日/周/月切换）
    ↓
Tab: [个人明细] [团队明细]
    ↓
列表/树形结构 + 筛选排序 + 导出
```

**迭代建议**：
- **一期（Must）**：统计概览卡片 + 个人明细Tab + 团队明细Tab（完整数据列） + 时间筛选 + 排序 + 搜索
- **二期（Should）**：团队树形结构 + 业绩趋势图表 + 数据导出 + 粉丝详情页

**菜单建议**：在供应端侧边栏新增一级菜单"分销业绩统计"，图标建议使用 `BarChartOutlined` 或 `TeamOutlined`

**参考现有模式**：PC端已有完整的列表+筛选+弹窗交互模式（参考 `supplier/partner/index.jsx`），复用相同技术方案

### 4.3 需要进一步明确的

- 粉丝层级关系的具体绑定规则（邀请码链路 vs 消费绑定）
- 业绩计算的具体口径（仅消费金额，还是包含佣金分佣）
- 图表组件选型（使用 antd charts 还是 echarts）
