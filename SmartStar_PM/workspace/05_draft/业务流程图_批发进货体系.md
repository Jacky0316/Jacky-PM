# 星马特平台 - 批发进货体系 业务流程图

## 一、供应商端 → 门店端 批发进货主流程

```mermaid
flowchart TD
    subgraph 供应商端
        A1[供应商注册/登录]
        A2[添加合作门店]
        A3[设置门店等级 1-5级]
        A4[配置商品批发价<br/>全局折扣/等级折扣/商品级折扣]
        A5[管理进货订单<br/>审核/发货]
    end

    subgraph 平台系统
        B1[校验门店ID有效性]
        B2[生成批发价<br/>公式: 优惠价 × 折扣 × 等级折扣]
        B3[记录价格快照]
        B4[商品自动同步<br/>进货完结后触发]
        B5[自动结算<br/>T+N工作日]
    end

    subgraph 门店端
        C1[门店注册/登录]
        C2[查看合作供应商<br/>及商品批发价]

        C4[查看物流信息]
        C5[确认收货]
        C6[商品入库<br/>商品库管理]
    end

    A1 --> A2
    A2 --> B1
    B1 --> A3
    A3 --> A4
    A4 --> B2
    C1 --> C2
    C2 --> C3
    C3 --> B3
    B3 --> A5
    A5 --> C4
    C4 --> C5
    C5 --> B4
    B4 --> C6
    C5 --> B5
```

## 二、详细业务流程时序图

```mermaid
sequenceDiagram
    autonumber
    participant 供应商
    participant 平台系统
    participant 门店
    participant 财务系统

    %% 阶段一：合作建立
    供应商->>平台系统: 添加合作门店(门店ID)
    平台系统->>平台系统: 校验门店ID有效性
    平台系统->>平台系统: 同步门店基础信息
    供应商->>平台系统: 设置门店等级(1-5级)
    供应商->>平台系统: 配置商品批发价规则

    %% 阶段二：门店采购
    门店->>平台系统: 查看合作供应商及商品批发价
    门店->>平台系统: 创建进货订单(选商品+数量)
    平台系统->>平台系统: 生成价格快照
    平台系统->>供应商: 推送新订单通知

    %% 阶段三：供应商履约
    供应商->>平台系统: 审核订单(通过/拒绝)
    供应商->>平台系统: 填写物流信息发货
    平台系统->>门店: 推送发货通知

    %% 阶段四：门店收货
    门店->>平台系统: 查看物流进度
    门店->>平台系统: 确认收货
    平台系统->>平台系统: 触发商品自动同步

    %% 阶段五：结算
    平台系统->>平台系统: 生成结算单
    平台系统->>财务系统: 发起结算(T+N日)
    财务系统->>供应商: 结算款项到账

    Note over 供应商,门店: 进货订单完结 → 商品自动同步至门店商品库
```

## 三、商品批发价计算逻辑

```mermaid
flowchart LR
    subgraph 批发价计算公式
        direction TB
        F1[优惠后价格<br/>promotion_price]
        F2{是否有<br/>自定义折扣?}
        F3[使用商品级折扣<br/>custom_discount]
        F4[使用全局折扣<br/>global_discount]
        F5[门店等级折扣<br/>level_discount]
        F6[最终批发价<br/>final_price]
    end

    F1 --> F2
    F2 -->|是| F3
    F2 -->|否| F4
    F3 --> F5
    F4 --> F5
    F5 --> F6

    style F6 fill:#90EE90
    style F1 fill:#87CEEB
    style F5 fill:#FFD700
```

**计算公式**：
```
最终批发价 = 优惠后价格 × (自定义折扣 OR 全局折扣) × 门店等级折扣
```
