## 一、需求背景分析

### 1.1 当前业务现状

现有线上商城（H5端）已支持快递配送方式，用户可在线浏览商品、下单购买、商家通过快递发货配送。

### 1.2 核心痛点

1.  **用户侧**：快递费用增加购物成本；部分用户有到店自取的时间和地点灵活性需求。
2.  **门店侧**：线下门店缺乏有效引流手段，用户到店后可促进额外消费机会未被激活。
3.  **平台侧**：配送场景单一，订单履约成本较高，门店资源未充分利用。

### 1.3 受影响角色

| 角色 | 说明 |
| --- | --- |
| C端用户 | 下单时选择自提方式，到店出示核销码取货 |
| 门店店员 | 查看自提订单、核销自提码、完成交付 |
| 商城运营管理员 | 管理自提门店配置、监控自提订单数据 |

## 二、需求目标确认

### 2.1 核心目标

为线上商城增加"到店自提"配送方式，用户可选择就近门店自提，节省快递费用；同时为线下门店引流，促进到店附加消费。

### 2.2 具体目标

| 目标编号 | 目标描述 | 可衡量标准 |
| --- | --- | --- |
| G1 | 用户下单时可选择"快递配送"或"到店自提"两种配送方式，在选择到店自提时，自动匹配自提门店（基于收货地址或实时定位），最后支付生成自提订单。 | 用户自提订单下单支付流畅完成，自提订单量占比​ > 30% |
| G2 | 用户到店出示核销码，门店扫码/输入核销码顺利完成核销 | 核销操作成功率 >= 99% |
| G3 | 支持用户在下单后、未核销前取消订单并自动退款 | 取消退款及时到账 |

## 三、业务流程分析

### 3.1 当前流程（现状）

```
graph LR
    A[用户浏览商品] --> B[加入购物车]
    B --> C[下单支付]
    C --> D[商家发货]
    D --> E[快递配送]
    E --> F[用户确认收货]
```

**现状流程说明**：现有流程仅支持快递配送，无自提选项。

### 3.2 目标流程（改善后）

```
graph TD
    subgraph 下单页流程
        A1[用户浏览商品] --> A2[加入购物车]
        A2 --> A3[进入结算页]
        A3 --> A4{选择配送方式}
        A4 -->|快递配送| A5[填写收货地址]
        A4 -->|到店自提| A6[系统默认匹配最近门店]
        A6 --> A7[用户可修改选择其他门店]
        A7 --> A8[选择自提时间段]
        A8 --> A9[提交订单并支付]
    end

    subgraph 核销取货流程
        B1[支付成功后生成自提码] --> B2[系统推送取货通知给用户]
        B2 --> B3[用户按时间段到店]
        B3 --> B4[用户出示自提码/核销码]
        B4 --> B5[店员扫码或输入核销码]
        B5 --> B6{核销成功}
        B6 --> B7[订单完成，取货成功]
    end

    subgraph 取消退款流程
        C1[用户申请取消订单] --> C2{订单状态}
        C2 -->|未核销| C3[自动退款]
        C2 -->|已核销| C4[拒绝取消]
        C3 --> C5[退款及时到账]
    end

    subgraph 门店管理流程
        D1[运营管理员配置自提门店] --> D2[设置门店营业时间]
        D2 --> D3[门店绑定可售商品/库存]
    end
```

### 3.3 关键子流程详述

#### 3.3.1 自提时间段的校验逻辑

```
graph LR
    A[用户选择门店] --> B[获取门店营业时间]
    B --> C[展示可预约时间段]
    C --> D{用户选择时间段}
    D -->|在营业时间内| E[允许提交]
    D -->|超出营业时间| F[提示选择其他时间]
```

## 附录：关键规则确认汇总

| 规则维度 | 确认结论 |
| --- | --- |
| 自提费用 | 自提不收取快递费用，与快递配送同价 |
| 营业时间限制 | 用户需选择自提时间段，必须在门店营业时间内 |
| 核销方式 | 支持扫码核销和输入核销码，两种方式都要 |
| 订单修改 | 不支持将自提订单修改为快递配送 |
| 取消订单 | 未核销前可取消，自动退款，及时到账 |
| 门店匹配 | 默认匹配离用户地址最近的门店，允许用户手动切换 |
| 未付款订单 | 未付款订单不生成核销码，无法核销 |
| 批量核销 | 不支持批量核销 |
