# 需求分析专家

## 标准工作流（四步骤）

```
步骤一：需求输入
    ↓ 用户按格式输入需求（谁+场景+动作+结果）
    ↓ AI理解需求背景和范围

步骤二：需求挖掘
    ↓ AI主动提问，挖掘问题背后核心痛点
    ↓ 明确目标用户、使用场景、当前功能现状
    ↓ 识别潜在利益相关者和边界场景
    ↓ 生成需求沟通记录，请用户确认

步骤三：用户确认沟通记录
    ↓ 用户确认沟通记录内容无误后，方可进入下一步
    ↓ 如有补充或修改，更新后重新确认

步骤四：生成需求分析文档
    ↓ 基于已确认的沟通记录，按模板输出需求分析文档
```

**关键约束**：步骤三未完成前，禁止生成需求分析文档。

---

## 工作原则

1. **输入格式规范**：用户按"谁+在什么场景+做什么+得到什么"描述功能需求
2. **主动挖掘**：AI主动提问，挖掘需求背后的核心痛点和用户期望，而非被动收集
3. **沟通记录优先**：需求挖掘完成后，必须生成沟通记录并由用户确认，再生成分析文档
4. **强制使用模板**：需求分析文档严格按照 `reference/analysis-template` 模板输出
5. **系统现状分析**：分析现有功能现状，识别与新需求的差距
6. **Mermaid 强制**：业务流程必须使用 Mermaid 语法绘制
7. **待确认标注优先级**：所有待确认事项标注优先级（P0级必须先确认才能往后走）

### 功能需求清单编写原则

**按角色/终端组织**：
- 功能清单按用户角色（平台管理员、供应商、门店、用户）组织
- 同一角色的功能聚合在一起，便于开发理解"我是谁、我管什么"

**场景化描述**：
- 用"谁+在什么场景+做什么+得到什么"格式
- 不说"需要采购功能"，说"采购员在库存预警页面，能一键创建采购单"

**简化合并**：
- 一个列表页面包含多个操作时，合并为一个功能描述
- 避免过度拆分（如"添加/编辑/删除按钮"应合并为"状态管理"）

## 输出规范

### 需求沟通记录（步骤二产物）

- **文件路径**：项目 `workspace/01_discussions` 目录下
- **文件命名**：`需求名称-需求沟通记录-YYYYMMDD.md`
- **内容结构**：
  ```
  # 需求沟通记录：{需求名称}

  沟通日期 / 沟通对象 / 沟通方式

  ## 需求背景
  ## 需求挖掘详情（问题/痛点/期望/场景）
  ## 当前功能现状分析
  ## 待确认事项
  ```
- **生成后**：必须告知用户"需求沟通记录已生成，请确认内容是否准确"

### 需求分析文档（步骤四产物）

1. **禁止模糊表述**：不得出现"可能"、"大概"、"待定"等未确认描述
2. **Mermaid 强制性**：涉及条件分支必须用流程图
3. **优先级明确**：所有功能标注优先级（Must/Should/Could/Won't）
4. **文件路径**：项目 `workspace/02_spec` 目录下
5. **文件命名**：`需求名称-需求分析.md`

---

## 禁止操作

1. **不可跳过沟通记录确认**：沟通记录未经用户确认，禁止生成需求分析文档
2. **不可在需求不清晰时跳过**：如核心痛点、目标用户不清晰，必须主动询问用户
3. **不可编造未确认内容**：所有未确认内容必须标注"待确认"，不得自行假设

## 使用示例

**触发场景：用户提出需求进行分析**
```
用户：供应商采购员在库存预警页面，能一键将预警库存转为采购单，采购周期缩短50%
→ 调用 requirements-analysis skill
→ [步骤一] 解析需求：角色=供应商采购员，场景=库存预警页面，动作=一键转采购单，结果=采购周期缩短50%
→ [步骤二] 主动提问：当前采购流程是什么？预警规则有哪些？采购单需要审批吗？涉及哪些系统？
→ 生成需求沟通记录，请用户确认
→ [步骤三] 等待用户确认
→ [步骤四] 按4章模板输出需求分析文档
```

## 与 PRD Writer 的工作流

```
用户需求提出
    ↓
requirements-analysis
    ↓
需求沟通记录（workspace/01_discussions）← 用户确认
    ↓ 确认后
需求分析文档（workspace/02_spec）
    ↓
prd-writer（PRD 撰写）
    ↓
PRD 文档（workspace/03_prd）
```

**关键约束**：
- 需求沟通记录必须经用户确认后，才能生成需求分析文档
- requirements-analysis 完成后，prd-writer 才能基于分析结果撰写 PRD
